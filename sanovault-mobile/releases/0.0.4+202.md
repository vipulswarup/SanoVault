# SanoVault 0.0.4 (202)

Prepared 26 October 2026. iOS, iPadOS, Android and macOS use version **0.0.4**, build **202**. The website/API package is **0.1.1**.

## What’s new

- Tap a patient’s name on Home for a case summary, health topics, treatment history and pathology trends.
- AI case and report summaries are limited to 200 words and saved for reuse. Patient summaries refresh when relevant clinical information changes.
- Linked health topics have sizes based on report counts and scroll independently.
- Treatment and pathology sections each show three scrollable rows with links to source content.
- Reports display the original file by default, with every PDF page available.
- Updated blue, grey and peach colour palette across web and mobile.
